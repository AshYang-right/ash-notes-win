# Third-party scope

The root MIT license applies to original AshNotes code and documentation.
Dependencies and imported assets retain their own licenses and notices.

The committed npm lockfile records these direct dependency license identifiers:

| Dependency | Lockfile license |
| --- | --- |
| React and React DOM | MIT |
| lucide-react | ISC |
| @tauri-apps/api | Apache-2.0 OR MIT |
| @tauri-apps/plugin-opener | MIT OR Apache-2.0 |

This inventory does not replace upstream license texts or a complete transitive
dependency notice bundle. Review Rust crates and all dependencies when distributing
binaries.

Starter artwork needs provenance review before a public release:

- `public/vite.svg`
- `public/tauri.svg`
- `src/assets/react.svg`
- `src-tauri/icons/` (application and installer icons)

Retain appropriate upstream notices or replace these with artwork of documented
origin. The project license does not grant rights to upstream trademarks.
